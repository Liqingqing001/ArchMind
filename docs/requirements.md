# AI 技术知识平台 · 第一期需求与验收

状态：工作基线 v0.1；用户提供的产品构想为需求来源。用户已确认：后台完整闭环优先、推荐技术栈、个人使用并预留多人扩展，提供本地与 Docker 部署。

## 产品与范围

知识库本身是产品。第一期交付个人使用的中文知识管理后台，完成分类、实体、关系、来源、巡检、快照、变更审核、事实版本与检索追溯。前台智能顾问、自动 LLM 抽取、向量检索、商业价格计算、报告生成、复杂权限和多租户属于后续迭代，不能以静态界面宣称完成。

已确认技术方案：React + TypeScript + FastAPI + SQLAlchemy；生产 PostgreSQL，本地 SQLite 降低启动成本；独立 APScheduler 进程负责调度；公开 HTTPS 来源，禁止内网地址。先本地验收，不将未配置的 Python API 伪装成已部署网站。

## 用户故事与验收标准

| 功能 | 验收标准 |
| --- | --- |
| 分类 | 支持父子分类、实体关联多个分类，查询父分类包含后代 |
| 实体 | 厂商、品牌产品、模型、API 服务、开源项目和框架分别建模；可创建、编辑、检索并关联 |
| 来源 | 注册 HTTPS URL、类型、周期，暂停/启用，查看检查状态 |
| 巡检 | 手动与独立调度执行；有开始/结束/错误；同来源避免并行执行；失败可手动重试 |
| 变更检测 | 条件请求、正文哈希；未变化不重复建快照；变化只生成候选，不直接发布事实 |
| 快照 | 保存有大小限制的原始响应和规范化文本，可浏览来源、时间、哈希 |
| 提交审核 | 字段、值、快照、证据必须完整；证据须为快照片段；结构化 facts JSON 可抽取候选 |
| 审核 | 审批/驳回有记录；审批事务中更新事实；过期候选返回冲突，不覆盖较新事实 |
| 历史 | 保留事实每个版本；回滚通过新的候选及审核完成，不删除历史 |
| 检索 | 仅查已发布事实，返回版本、证据、快照、来源和可回查 trace；明确为关键词检索 |
| 示例 | 示例实体/来源/证据显式标识，不宣称是实时能力或价格 |

## 非功能要求

- 输入校验、数据库约束、事务与乐观并发控制；API OpenAPI 文档。
- 配置与密钥通过环境变量；前端不内置第三方密钥。
- 本地默认 loopback，生产配置管理口令；当前单一管理员身份。
- 自动测试覆盖审核冲突、来源失败、重复巡检、证据一致性、检索隔离与权限。
- 提供版本迁移、锁文件、CI、容器编排、备份恢复说明。
