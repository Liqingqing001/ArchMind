## 可重复导入

资料集保存在 `backend/data/official-knowledge-2026-11-07.json`。SQLite 导入器使用 Node.js 22.16+ 的内置 SQLite 模块，不依赖 Python 环境。当前数据库须已完成项目迁移。

```powershell
node scripts/import-official-knowledge.mjs
node scripts/verify-official-knowledge.mjs
node scripts/import-official-knowledge.mjs --apply
```

第一条只校验；第二条在内存数据库中验证导入逻辑；第三条先生成一致性备份再写入 `backend/knowledge.db`。备份在 `artifacts/backups/`，可用 `--db=绝对路径` 指定另一个已迁移的 SQLite 库。此导入器不适用于 PostgreSQL。

重复导入不产生重复事实；遇到已有不同值会创建待审核变更，不直接覆盖。事实来源保留核验日期、URL、摘录与 SHA-256；发布记录明确标注 `curated_web` 和 Codex 编辑核对身份。
