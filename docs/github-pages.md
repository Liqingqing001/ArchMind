# GitHub Pages 公开体验版

已经实现同一套 React 界面的静态体验模式，保留本地新增的对话、知识库、模型下载与管理入口。完整后端构建仍调用真实 FastAPI，Pages 构建通过独立适配器使用浏览器本地状态。

## 体验内容

- 117 个公开知识实体、215 条资料事实，来自仓库内的三份公开资料数据集，核验日期沿用 2026-11-07；不是当前实时巡检结果。
- 20 个开放权重模型的官方模型卡、许可证与下载链接。
- 额外 1 个显式标注的虚构 Atlas 模型、2 条虚构事实和待审核变更，用来体验审核、版本恢复与检索生效。
- 可选两种对话：未配置 API 时为明确标注的静态演示；配置后由浏览器直连用户选择的 HTTPS 模型接口，使用本地已发布知识进行真实回答并校验引用。支持 Chat Completions、Responses、Claude Messages 协议。
- 本地对话新建、连续追问、重命名、删除撤销、刷新恢复和 Markdown 导出。
- 可见的检索记录、查询时版本、来源快照与证据。审核通过后当前事实改变，旧记录仍保留当时版本。
- 模拟操作与对话仅保存到当前浏览器，不写入仓库或服务器，也不会影响其他访客；“重置演示”只清除知识与对话状态，模型设置需要在连接弹窗中单独清除。浏览器禁用存储时使用本页内存。

点击右上角“连接模型”，填写服务商、API Key、模型 ID 和地址，测试后保存。设置与密钥明文存于当前浏览器，可单独清除；只在请求时发送给所选服务商，绝不进入对话、检索记录或公开构建资产。供应商必须允许浏览器跨域（CORS）。认证、协议或网络错误不会降级成演示回答。自动巡检和服务器数据库持久化仍使用完整后端版。

## 构建和本地预览

```bash
cd frontend
npm ci
npm run test:demo
npm run build:demo
npm exec vite -- preview --host 127.0.0.1 --port 4173
```

访问 http://127.0.0.1:4173/ArchMind/ 。项目子路径由构建命令明确设为 `/ArchMind/`。静态知识文件在构建时生成，只读取已提交的公开 JSON 数据集，不读取本机数据库、环境凭据或个人对话。

`npm run build` 仍是普通后端模式。`frontend/.env.demo` 只有公开构建开关；任何 VITE_ 环境变量都会进入公开资产，不能在里面填写凭据。

## GitHub 发布

工作流：`.github/workflows/pages.yml`。

PR 自动执行演示行为测试和构建，只生成预览 artifact。合并 main 后执行 Pages 发布；工作流也支持在 Actions 中手动运行。

仓库已启用 GitHub Actions Pages 部署；可在 [Settings → Pages](https://github.com/Liqingqing001/ArchMind/settings/pages) 查看配置。

预期默认项目地址：https://liqingqing001.github.io/ArchMind/ 。上线以 Pages 工作流部署成功及该地址实际返回页面为准。

## 验收路径

1. 首页输入“我想做 AI 视频短剧”，先回答预算、使用方式、操作经验、规模与关键要求。无 API 时使用明确标注的交互演示。
2. 刷新确认摘要恢复；点击“确认需求，生成简版方案”后才展示建议和引用。修改预算会重新要求确认。
3. 知识库中打开 Qwen3-8B，查看模型卡与官方下载入口。
4. 知识管理 → 版本与审核，在虚构 Atlas 条目中审核上下文变更。
5. 检索调试 → Agent 模拟 → 包含演示数据 → 搜索“上下文窗口”，确认返回 v2 / 128K。
6. 回查旧 trace 核对版本；点击重置恢复最初状态。

## 分类与数据升级

知识库默认提供场景路线指南，明确区分编辑建议与产品事实；可切换“按能力浏览”，其中首页只显示能力分组。选择“生成类 → 大语言模型 → 阿里云”后，才展示该厂家的具体模型；理解类提供文字、图片、声音、视频四个入口。侧栏支持逐层展开、折叠，手机通过分组卡片和路径导航完成同样操作。开放权重是模型标签，不再独立成第二份目录。多能力模型共用同一实体、事实与版本；保留浏览器已有对话、审核操作与检索记录。规则与维护方式见 [分层知识目录](knowledge-navigation.md)。

## 完整后端版

GitHub Pages 只托管静态 HTML/CSS/JavaScript：[官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。Pages 现在可以使用访客自带 API 直接调用允许 CORS 的模型服务。若供应商禁止浏览器直连，或者需要自动采集、服务端数据库和多人权限，则另外部署 FastAPI/PostgreSQL/worker。不能将管理口令或任何共用模型密钥内置进 Pages。
