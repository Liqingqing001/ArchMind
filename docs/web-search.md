# 联网检索与库内知识融合

## 使用

先在“连接模型”配置文本模型，再打开“联网检索”，选择 Tavily 或博查、填写独立搜索 Key 并保存（首次配置默认勾选自动核验，已有关闭设置不会被覆盖）。模型 Key 不等同搜索 Key。设置分别保存在浏览器 `archmind-model-settings-v1` 与 `archmind-web-search-settings-v1`，清除搜索配置不删除模型配置、会话或审核记录。

Pages 直接调用所选搜索服务的固定 HTTPS API；完整后端版由 FastAPI 调用。Tavily 和博查针对 Pages Origin 的 OPTIONS 预检返回允许跨域头。进一步用 Chromium 和无效测试占位符检查时，博查能跨域返回 401，Tavily 的认证失败表现为网络／CORS 错误。因此 Pages 默认选择博查；两者的真实成功搜索仍需有效 Key、额度、账户权限和服务商当时 CORS 策略。没有内置共享 Key 或公共代理，不应把密钥放入 VITE_、静态文件或仓库。

目标明确的首轮选型就开始搜索，无需收齐条件。测试检索发起一次请求；每次新选型/条件修改/价格问题/正式方案最多三次查询，每次最多四条候选，交替合并后优先保留官网、去重并限制为六条。实时语音和生图分别覆盖火山/阿里、腾讯/智谱及相关海外官网；Tavily 同时使用 include_domains，博查使用带 site: 范围的查询。查询模板是发现线索，不固定候选赢家，也不能保证各站全部被覆盖。

Tavily 请求 basic 深度与可选正文，博查请求摘要。对于上述专题返回的官网摘要，进一步尝试读取最多三篇正文：完整后端使用既有公开 HTTPS/DNS 校验采集器；Pages 发起无凭据 GET，受目标官网 CORS 限制。读取失败保留摘要、展示限制，不伪称读过全文。未经支持的动态页面可能仍需人工核验。两家搜索都可能计费，以服务商规则为准。

没有明确目标时不搜索。单纯解释且条件未变时可复用最近30分钟内同一会话的证据，显示“沿用近期官网资料”和原日期；过期、无结果、条件变化或时效问题重新搜索。显式续写保持原证据和编号，不额外搜索。

## 回答依据

- [K1]：数据库或访客本地库内的当前已发布事实，带原有来源、快照和事实版本。
- [W1]：本轮搜索服务返回的页面摘录或搜索摘要，带 URL、检索时间；来源确实提供时才显示页面日期。检索时间不等同页面更新时间。
- 未知 [K]/[W] 编号统一标记为待核验。没有检索到的网页不能作为已搜索的证据。
- 成功、空结果、部分失败、失败分别展示。服务失败时明确提示本轮仅使用库内资料，不伪装成已获得最新答案。

回答下方“本轮联网依据”可打开链接、查看摘录、关键词、服务商和日期。库内 trace 的 request_context 保存同一份网页证据，知识管理的检索记录可回查。导出 Markdown 带网页引用 URL 和检索时间。网页不会自动覆盖库内价格或参数，也不会自动成为已审核事实；仍需登记来源并走现有候选审核流程。

## 实现边界

共享规则为 `backend/data/web-search-policy.json`，浏览器适配器为 `frontend/src/webSearch.ts`，后端为 `backend/app/web_search.py`。只接受 Tavily／博查固定服务地址，不从网页执行命令、不自动跟随带凭据请求的跳转、不抓取结果中的任意私网地址。检索请求只使用任务与本轮问题构造的有限关键词，不上传全部聊天；已知模型和搜索 Key 会从查询及结果中移除。

每个请求 20 秒超时、响应 2 MB 上限、摘录 3200 字符上限；Pages 官网读取另设12秒超时，完整后端沿用采集器的20秒请求/25秒读取总时限。网页作为不可信资料传给模型，要求区分日期和冲突，不能把最低营销价视为实际报价或库存。官网域名优先是来源筛选信号，不代表内容已审核。首次选型约500～800字，正式方案约800～1200字，解释方案选择、使用方向与成本，保留可点击的网页及库内引用；网页未被正文引用时显示明确提醒，不能把“搜索成功”当成“已经采用”。

## 验证范围

2026-11-15：新增前后端共用的对话路由用例，覆盖首轮只有语音目标即检索并回答、解释复用30分钟内证据、预算变更/现价/正式方案重新检索，以及官网读取失败保留摘要。独立无头 Edge 在1440与390像素下验证了这些多轮操作、两段对话与刷新恢复，输入框可见、页面无横向溢出。模型与搜索使用受控响应，未调用真实付费接口；此验收证明数据链路和交互，不等同模型生成质量评测。

此前的前后端受控 HTTP 测试覆盖协议、凭据隔离、引用、错误与续写；早期 Chromium 验收使用受控搜索及模型响应，未使用用户真实 Key。静态平台资料来自本次实际公开网页核对，与受控联网适配器测试分开记录。

### 2026-11-08 实际 Tavily 验证（历史流程）

使用用户授权的临时测试密钥调用官方搜索接口（密钥未记录）。小说场景旧词主要返回部署与 API 文档；新增“AI 小说写作平台、长篇、大纲、角色、章节、官方价格”发现查询后，返回唐库创作网、马良写作等候选，以及 DeepSeek 官方价格页。网页宣传仍需核验，不能把效果或免费额度当保证。Chromium 使用真实 Tavily 成功响应验证 CORS、澄清期间不搜索、确认后将结果传入文本模型请求、引用链接与评价归档。自然语言模型在验收中使用受控响应，未使用用户模型密钥，因此这验证的是完整数据链路与交互，不是特定模型的生成质量。

若完整首稿没有任何有效网页引用，生成阶段最多追加一次文本模型修订（沿用同一批网页，不追加搜索），尝试把相关平台整合进方案。仅在修订完整且带有效网页引用时采用；失败、无关或再次截断则保留完整首稿并提示未成功整合。此分支会增加一次修订调用和等待时间；修订与首稿共享最多两次自动补写额度，结果记录 `grounding_repair`；显式续写不触发修订。
